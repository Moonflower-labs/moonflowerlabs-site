# Moonflower Labs

Moonflower Labs website built with React Router, React, Tailwind CSS and TypeScript.

Requires Node.js 26.

```sh
nvm use
npm ci
npm run dev
```

Check and build:

```sh
npm run typecheck
npm run build
npm start
```

Add shadcn UI components:

```sh
npm run ui -- add <component>
```

Hosted on Vercel using the configuration in `vercel.json`.
